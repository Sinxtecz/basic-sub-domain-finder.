> 🐍 Simple Python subdomain scanner made for learning cybersecurity.

## ⚡ Features

* 🔎 Subdomain enumeration
* 📄 Wordlist support
* 🌐 HTTP requests
* ⏱️ Request timeout
* 🛡️ Basic error handling

## 🚀 Usage

Install the required library:

```bash
pip install requests
```

Run:

```bash
python scan.py
```

Enter your target domain when asked:

```text
Enter the domain: example.com
```

The scanner will then test subdomains from the wordlist.
